# Etapes d'installation
- cloner le repo pour récupérer l'app
- lancer `npm install` pour récupérer les dépendances nécessaires dans leurs bonnes versions
- faire une copie _.env.local_ du fichier _env_ et y entrer les identifiants MySQL
- dans un Terminal MySQL coller les requêtes du fichier _adaopte.sql_ pour créer la base de données
- lancer `npm run server` et `npm run dev` pour consulter l'app dans le navigateur
